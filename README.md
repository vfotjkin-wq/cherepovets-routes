# Интерактивные маршруты Череповца (Cloudflare Pages)

Статический сайт на чистом **HTML, CSS и JS** без сторонних зависимостей и этапа сборки.

## Структура проекта
- `index.html` — разметка всех экранов и модальных окон
- `styles.css` — тёмная лаконичная стилизация и адаптивная вёрстка
- `app.js` — hash-навигация, интерактивные задания, зум карт, таймер и сохранение прогресса в `localStorage`
- `assets/` — фотография моста и карты пяти маршрутов

## Деплой на Cloudflare Pages
1. Откройте **Cloudflare Dashboard → Workers & Pages → Create → Pages → Direct Upload**.
2. Распакуйте этот архив и перетащите папку с `index.html`, `styles.css`, `app.js` и `assets/` в окно загрузки (либо подключите Git-репозиторий без команды сборки, указав корневую папку как Output directory).
3. Нажмите **Deploy site** — сайт готов к работе.
